# Assignment 06 — TaskFlow Capstone

Responsive task management SaaS-style capstone built with vanilla HTML, CSS and JavaScript.

## Features
- Create, read, update, delete tasks (CRUD)
- Status dashboard metrics
- To do / in progress / completed status
- Search and status filters
- Persistent task data with localStorage
- Responsive mobile/tablet/desktop layout
- Dialog-based task editor and accessible form labels

## Run
Open `index.html` in a browser. No build step or dependencies required.

## Note
This is a front-end capstone with simulated workspace identity; it does not include real server authentication or a backend database.
